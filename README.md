# Sky AI — Android starter

Sky is planned as a permission-controlled AI phone agent.

## V1 included
- AI command screen
- Global AI ON/OFF
- Screen-control and typing permission switches
- Calling/payment/trading safety switches
- Emergency STOP
- Accessibility Service foundation

## Planned next modules
1. Real command parser + AI backend
2. Permission firewall
3. Screen/UI understanding
4. Tap/scroll/type execution
5. Voice commands
6. Calling agent (answer/make calls with explicit permissions)
7. Content generation and social publishing
8. Research + memory/evaluation system
9. MT5 analysis and, only if explicitly enabled, execution with hard risk limits

Do not place AI API keys in the Android app. Use a secure backend for model/API credentials.
